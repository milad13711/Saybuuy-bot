# بات فروش Saybuuy — W1 Ultra Mini (پیام‌رسان بله)

این بات برای هدایت کاربران به صفحه‌ی لندینگ محصول و تشویق‌شون به خرید سریع
طراحی شده:
https://shop.saybuuy.com/offers/w1-ultra-mini

## چی توش هست؟

- `bot.py` — منطق اصلی بات (Long Polling، بدون نیاز به سرور/دامنه/HTTPS)
- `messages.py` — تمام متن‌های تبلیغاتی، جدا از کد، برای ویرایش آسون
- `requirements.txt` — وابستگی‌های پایتون
- `.env` — توکن بات (از قبل با توکنی که فرستادید پر شده)

## محتوایی که در بات استفاده شده

از صفحه‌ی لندینگ استخراج شده:

| مورد | مقدار |
|---|---|
| محصول | ساعت هوشمند W1 Ultra Mini |
| قیمت با تخفیف | ۳,۴۹۷,۰۰۰ تومان |
| قیمت اصلی | ۵,۰۰۰,۰۰۰ تومان |
| میزان تخفیف | ۳۰٪ |
| پوزیشنینگ | آفر پایان فصل، هدیه برای نوجوان‌ها/جوان‌ها |

⚠️ **مهم:** روی صفحه‌ی لندینگ مشخصات فنی دقیق (مثل ضدآب بودن، ضربان‌سنج،
مدت باتری) یا شرایط گارانتی/ارسال به‌صورت متنی در دسترس نبود، برای همین در
پیام‌های بات از ادعاهای فنی مشخص و اثبات‌نشده پرهیز شده — چون تبلیغ نادرست
هم به اعتماد مشتری لطمه می‌زنه و هم می‌تونه از نظر قانونی مشکل‌ساز بشه. اگه
این مشخصات رو دارید، حتماً در فایل `messages.py` (بخش `FEATURES`) دقیق‌ترش
کنید — هرچی مشخص‌تر و واقعی‌تر باشه، تبدیل بهتری می‌گیرید.

## جریان مکالمه (Funnel)

1. کاربر `/start` می‌زنه → پیام معرفی محصول + قیمت + تخفیف + دکمه‌ی خرید
   (که مستقیم به لندینگ لینک شده) + دکمه‌های «ویژگی‌ها»، «چرا الان بخرم؟»
   و «قیمت»
2. هر کدوم از دکمه‌های اطلاعاتی که بزنه، محتوای مرتبط رو می‌بینه و **همیشه**
   دوباره دکمه‌ی خرید زیرش هست — یعنی از هر مسیری، حداکثر یک کلیک تا خرید
   فاصله داره.
3. هر پیام متنی دیگه‌ای (سؤال، سلام و ...) هم به سمت همون پیشنهاد اصلی
   هدایت می‌شه، تا مکالمه از مسیر فروش خارج نشه.
4. دستورات میان‌بر: `/price`, `/buy`, `/help`

نکته‌ی طراحی: دکمه‌ی خرید از نوع لینک مستقیم (`url`) به لندینگه، نه یه پیام
میانی — یعنی کاربر با یک کلیک از بله می‌ره روی صفحه‌ی پرداخت، بدون مرحله‌ی
اضافه. این خودش نرخ تبدیل رو بالا می‌بره.

## نحوه‌ی اجرا (روی هر سیستمی، حتی لپ‌تاپ شخصی برای تست)

```bash
cd saybuuy-bale-bot
python3 -m venv venv
source venv/bin/activate      # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

اگه اجرا و اتصال به `tapi.bale.ai` موفق باشه، لاگ «بات در حال اجراست...»
رو می‌بینید. حالا کافیه توی بله به بات‌تون پیام `/start` بدید.

برای توقف: `Ctrl+C`

## برای اجرای دائمی و ۲۴ ساعته (پیشنهاد هاستینگ)

بات با Long Polling کار می‌کنه، پس فقط لازمه یه سیستم *همیشه‌روشن* با
دسترسی به اینترنت اجراش کنه — نیازی به دامنه یا SSL نیست. ساده‌ترین
گزینه‌ها:

1. **یک VPS ارزان** (مثلاً با Ubuntu) — پروژه رو آپلود کنید و با
   `systemd` یا `pm2` (یا حتی `tmux`/`screen`) به‌صورت دائم اجراش کنید تا
   با ری‌استارت سرور هم بالا بیاد.
2. اگه سرور ندارید و می‌خواید سریع راه بیفته، هر سرویس ساده‌ی اجرای
   پایتون ۲۴ ساعته (Railway، Render، یک VPS ۱ گیگ رم و مشابه) کافیه —
   فقط باید `BALE_BOT_TOKEN` رو به‌عنوان متغیر محیطی ست کنید و دستور
   اجرا رو `python bot.py` بذارید.

نمونه سرویس systemd (روی لینوکس):

```ini
[Unit]
Description=Saybuuy Bale Bot
After=network.target

[Service]
WorkingDirectory=/path/to/saybuuy-bale-bot
ExecStart=/path/to/saybuuy-bale-bot/venv/bin/python bot.py
Restart=always
User=your_user

[Install]
WantedBy=multi-user.target
```

## شخصی‌سازی بیشتر

- همه‌ی متن‌ها در `messages.py` هستن — قیمت، درصد تخفیف، ویژگی‌ها و حتی
  متن دکمه‌ها رو از همونجا عوض کنید.
- اگه می‌خواید عکس محصول هم همراه پیام اول ارسال بشه، در `bot.py` به‌جای
  `send_message` در `handle_command` (حالت `/start`) از متد `sendPhoto`
  با همون کپشن استفاده کنید (مستندات API بله مشابه تلگرامه).
- اگه بخواید UTM یا شناسه‌ی ردیابی به لینک لندینگ اضافه کنید (برای
  اندازه‌گیری اینکه چند نفر از بات وارد شدن)، کافیه در `messages.py` مقدار
  `LANDING_URL` رو به چیزی مثل زیر تغییر بدید:
  `https://shop.saybuuy.com/offers/w1-ultra-mini?utm_source=bale_bot`

## نکته‌ی فنی مهم: فرمت متن در بله

مستندات رسمی بله (docs.bale.ai) رو چک کردم و برخلاف تلگرام، بازوی بله
پارامتر `parse_mode` نداره؛ متن هر پیام همیشه با فرمت اختصاصی خودِ بله
پردازش می‌شه: پررنگ با `*متن*` (با فاصله قبل/بعد)، ایتالیک با `_متن_`،
لینک با `[متن](آدرس)`، و **بدون پشتیبانی از خط‌خوردگی (strikethrough)**.
کد و متن‌ها بر همین اساس اصلاح شدن (قیمت قبلی/جدید به‌جای خط‌خوردگی، و
پررنگ‌ها با فاصله‌ی درست) تا مطمئن باشیم پیام‌ها درست نمایش داده می‌شن، نه
با ستاره‌های خام روی صفحه.

## امنیت توکن

توکن بات در فایل `.env` قرار داره. این فایل رو در جای عمومی (گیت‌هاب عمومی،
کانال، چت گروهی) قرار ندید — هرکسی که توکن رو داشته باشه می‌تونه به‌جای
شما پیام بفرسته. اگه فکر می‌کنید توکن لو رفته، از تنظیمات بات در بله
(@botfather بله) گزینه‌ی ری‌جنریت توکن رو بزنید.
